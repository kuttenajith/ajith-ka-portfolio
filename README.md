## Stack

- React 19 + TypeScript
- Vite
- Plain CSS (no UI kit)

All site copy is in [`src/content.ts`](src/content.ts). Change that file to update the page.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5174/ajith-ka-portfolio/](http://localhost:5174/ajith-ka-portfolio/)

```bash
npm run build
npm run preview
```

## Deploy

Pushes to `main` build the site and publish it on GitHub Pages (`/ajith-ka-portfolio/`).
